# 用户预测页面
作用：本人选择已发布模型并发起固定五交易日预测。实现：Vue3 script setup、请求键保护、版本明细与可访问图表；协议测试模拟数据，不代表真实效果。

PredictionResult展示固定五点图与可核对明细，包含版本依据，失败不展示曲线。sessionStorage仅保存按当前用户/股票隔离的请求标识，不存密码、验证码或预测结果；结果未知保留原键，终态释放。页面使用请求序号阻止账号/股票切换后的旧响应更新当前页面。

新一次发起前清空结果区，避免新模型请求失败时沿用上一条成功曲线；旧结果仍可通过本人历史单独查看。

VerificationPanel展示本人保存验证：未到期/等待核验/缺失/停牌/日历变更分别显示，零样本无指标；current指针与历史版本分开，预测虚线/实际圆点与相邻实线，不跨缺失点。价格与指标保留服务端字符串，仅绘图转换Number。刷新不触发训练/采集，失败保留已有结果；账号或预测变化同步清空并废弃旧异步响应。自动任务仍待D3B2。

ExplanationPanel：本人成功预测的MaaS解释，三段纯文本、事实引用与版本依据；首次仅发起一次、失败手动重试、未知操作复用、依据变动显式更新。账号变化立即清空并拒绝旧响应；生成失败保留预测与旧解释。

预测解释必须由用户点击生成。页面挂载、刷新记录、切换预测和账号均仅查询已有记录，不自动调用付费提供商；未知操作继续采用原编号恢复，不自动重试。
