# 管理员行情数据
作用：查看覆盖、历史版本、诊断，以及预检和登记当前 Baostock RAW 行情重取、查看操作记录。
实现方法：读取与写入入口分开；点击才预检/查询历史，无轮询。POST只发送一次；按账号与股票在sessionStorage保存规范原请求，未知结果先GET查询，确认未查到后才可人工同编号重发。退出/角色失效清理该账号恢复记录，迟到响应用请求代数隔离。原始排队回执与当前执行状态分别显示，不能把登记当更新成功。

固定版本详情新增VersionReferencesPanel：显式点击才GET候选引用；三owner分别时点，未知非0，数量不能相加或作为停用许可。换版本/账号清结果，身份拒绝通知父页；服务失败保留带旧时间结果。

VersionReviewPanel显式加载审核，乐观修订和幂等单次保存；sessionStorage保存按身份/版本隔离的未确认原命令，成功/权限撤销清除，刷新后通过GET核对，未知结果不自动重试。
MarketLifecyclePanel 为已发布的 Baostock 未复权固定版本提供使用状态、在途使用数及操作历史。管理员主动查询，历史可向前翻页；查询失败保留同版本已读结果，权限撤销时清空。
版本操作由服务端 actionsReady 控制。管理员确认原因后提交；结果不明时按账号和固定版本保留原请求，查询并核对原回执后更新页面。
