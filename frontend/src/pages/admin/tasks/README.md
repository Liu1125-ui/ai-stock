# 管理员任务工作区

TasksPage负责筛选、列表和游标导航；TaskDetailPanel负责所选任务详情；TaskAttemptsPanel保留原序号分页显示尝试历史。三处均按任务和账号/角色代次忽略迟到响应，只读取数据。taskPresentation统一上海日期、状态和耗时文案。taskFixtures为仅测试使用的合成数据与响应控制器，不是业务行情。

taskAccess为一次页面挂载内共享的访问边界；任一子请求返回403时同步清空所有区域并使旧请求失效，再查询账号权限。旧账号返回的403不能关闭新账号的工作区。

TaskActionsPanel展示后端操作条件、固定原因确认和绑定原编号的人工恢复；sessionStorage只保存可校验的固定请求字段，不含凭证或备注。未知结果先查询，人工恢复不变更编号/版本/原因且不自动POST。TaskOperationHistoryPanel独立只读游标分页，失败保留同scope旧页；共享taskAccess使任一区域撤权即清空全工作区。auth store在退出/换账号/降权时清理待恢复标记，页面未挂载时也生效。

训练任务标签页显示排队与执行状态、候选编号和取消审计。管理员显式确认取消原因，网络结果不明时保留原操作编号以供核对或重试。
