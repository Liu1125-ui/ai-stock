# 本人预测历史
作用：分页查看本人预测与隐藏记录；隐藏不会删除数值证据。实现：受会话保护API、详情与结果组件，页面不改写预测值。

历史详情采用列表代次与选择序号共同校验，快速切换记录时旧响应不得覆盖新选择；切换账号清空旧列表与详情。测试覆盖该竞态和隐藏后刷新，不把fixture结果当实际预测。

支持 /predictions?predictionId=UUID 打开本人详情；只接受合法UUID并复用服务端归属检查，初始请求失效或用户已另选时不覆盖。

同页的本人五日预测可以按已保存的同源证据融合预览。服务端校验模型仍已发布、修订号匹配以及相同输入版本和目标日。预览显示每个模型、融合参考价和朴素价格基线，计算不会新建预测记录。
