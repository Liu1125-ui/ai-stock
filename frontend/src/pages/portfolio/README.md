# 我的持仓
作用：手动维护本人数量与平均成本。实现：字符串输入、记录revision及持久requestId回执；当前页内存恢复未知请求，切账号清除。估值与AI分析由后续008B/FR-09提供。

## 估值分析面板
PortfolioAnalysisPanel单独展示当次保存的数量、成本、价格证据及定点计算，不与当前可编辑记录混算。生成必须点击，原请求恢复只保存本人键下的UUID；失败保留旧结果，跨账号异步响应失效。父页面仅在成功读取当前持仓后传递版本，失败传null。完整性、日期、新鲜度和旧版本均显示文字，不仅依赖颜色；窄屏显示卡片和可折叠证据。金额仅显示后端字符串，不使用JS浮点计算。

持仓问答面板：规则免费；发送问题才调用AI，告知仅绑定当前估值且刷新重置。恢复只存owner/analysis键下UUID，不存问题；未知请求先GET，可明确恢复原ID；本机恢复损坏/存储失败阻止新发送。账号/估值切换和卸载使迟到响应失效。
