# 行情页面
首页提供搜索和自选入口，分析页读取固定已发布版本并展示来源、截止日和四面板图。预测尚未接通时入口明确禁用。

StockAiAnalysisPanel：显示本人指定范围的AI行情分析；进入只查询，显式生成收费调用；未知结果复用操作号，切股票/周期/账号废弃旧回包，纯文本与来源依据展示。

E2b：本人同股成功预测分页选择，默认不引用；选择/刷新仅查询。未确认请求锁定原预测，保存结果显示原点、五目标参考价和验证版本；当前选择变化不替换历史内容。
StockQuestionPanel：绑定父面板已保存analysisId，建议问题只填输入；发送显式收费，未知结果保留原问题，刷新只读，明确恢复原请求。固定证据、历史回答与范围提示纯文本展示。
支持按保存分析的起止日期查询过往记录；新分析仍使用当前行情范围，跨日访问旧记录不必重新生成。
