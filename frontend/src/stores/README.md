# Pinia 状态

作用：保存工程联调页面状态与当前用户安全资料。
实现方法：`engineering.ts`区分未加载、载入中、成功与失败；`auth.ts`依据后端本人接口更新身份，不存储密码、验证码或会话凭据，退出清除资料，503不当成匿名加载成功。

profile用户ID改变同步使旧API请求代次失效；同账号昵称更新不触发，登录/退出/凭据变更由API同时失效旧代次。旧响应不得以新账号重放写操作。
questionRecovery.ts：同标签页sessionStorage仅保存当前用户/分析的未确认问题与操作号；NFC/码点检查，写入失败阻止发送，终态/退出/换账号清理，不保存凭据或完整回答。

inbox.ts：缓存当前用户未读数量，身份改变同步清空，忽略旧请求；失败显示未知，不轮询、不持久化消息正文。

marketReviewRecovery仅清理指定账号的全部版本审核恢复命令；auth在换号、退出和管理员降权时调用，面板权威拒绝时同样清理，普通导航仍可恢复原请求。
