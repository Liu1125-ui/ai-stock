## 展示规则

- 价格MAE/RMSE展示4位小数；归一化及基线误差展示6位小数。
- 方向准确率展示百分比（2位小数）及已核验点命中数。命中数只统计VERIFIED且具有明确directionHit的点，数据不完整时仅说明有效点数量，不推测命中数。
- 相对基线改善展示百分比（2位小数），负值保持负号。
- 空值或非有限值保持“暂无有效值”；零有效点仍不显示指标。
- 页面说明方向相对预测原点收盘价判断，汇总值四舍五入仅用于展示；逐点明细及后端精度不变。
