# Task6 管理员行情版本生命周期接口

沿用父计划。先做只读状态和历史，复用行情管理员会话校验及 no-store；再做原请求查询和受控写入。全局停用在能力及隔离演练完成前保持关闭。

1. 状态与历史：沿用现有股票和版本路径层级，严格校验路径及查询字段。对管理员区分原行情 AVAILABLE 和新业务许可，显示当前版本禁止停用、在途数量、版本修订号及写入是否可用。
2. 权限与边界：市场直连和网关均使用精确路由、管理员权限和不缓存；POST 校验唯一来源、操作标识头、严格 JSON 字段和字节上限，拒绝客户端传入操作者及目标地址。
3. 持久操作：重试查询复用原 operationId，绑定会话中的管理员和固定版本；超时只提示查询原请求。历史按固定版本分页，无秘密和完整上游响应。
4. 就绪检查：只探测本机配置中的服务，逐项确认实际注册和完成证明能力；未知、超时和错误一律拒绝写。保持生产默认关闭。
5. 先 HTTP 回归，再真 MySQL 并发、网关验证和独立审查；分成只读、写入及就绪三个可审核小步。

Task6A已完成市场服务只读实现和直接请求的权限回归（本地 HTTP 7 项通过）。界面通过同源网关访问；此阶段不为直接跨域浏览器访问增加 CORS 放行。下一步为网关只读代理、类型校验、权限回归。
