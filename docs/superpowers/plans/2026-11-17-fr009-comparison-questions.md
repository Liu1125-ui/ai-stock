# FR-09 已保存多股对比自由问答

用户在一份本人已保存的多股对比下提问。问答与原说明分开展示，回答依据始终指向提问时采用的对比编号、来源指纹、公式版本与服务端选取的事实条目。历史回答在刷新或服务暂不可用后仍能读取。

## 实施顺序

1. 使用严格请求解析读取 operationId、comparisonId、question、disclosureAccepted。复用现有问句长度、规范化和敏感文本校验。从登录会话确定 owner，先按 owner 和 comparisonId 查询保存对比，再生成事实。只使用服务端已计算的时间范围、指标、相对关系和缺口说明。
2. 复用现有比较解释的 ComparisonAiFacts 校验与引用字段，固定新的问答提示词版本。为模型调用单独实现模板和输出解析。输出只接受回答或证据不足两类结果，引用限定为本次事实的键，具体指标值和单位由服务端从事实中渲染。覆盖无共同端点、缺指标、引用越界、文本中夹带无依据数值和问答超出证据范围。
3. 为提问创建持久操作与回答记录。按 owner 和 operationId 幂等，同一编号更换对比或问题返回冲突。记录证据和提示词指纹，继承共享 AI 调用锁及预算，模型超时先查原操作。原比较和固定解释继续经现有入口读取。
4. 在比较页为当前保存记录提供发送、查询原请求和分页历史。问题输入与云端披露使用明确提示，登录人与对比切换后丢弃旧响应。验证页面刷新、重复点击、错误状态和异账号访问。
5. 隔离数据库和模拟 DeepSeek 接口先完成全链路验收。上线时生成开关初始关闭，实际付费验收沿用已经确认的单次授权方式。
