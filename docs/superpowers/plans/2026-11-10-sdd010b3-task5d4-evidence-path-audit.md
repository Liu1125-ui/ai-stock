# Task5D4 行情证据入口审计

1. 逐入口核对实际调用方、操作身份、固定RAW、读取/发布事务和终态释放；把历史读取、原任务查询与新计算区分开。
2. 正式五日预测通过 FORECAST 保护原始窗口、输入发布和后续读取；离线维护脚本无任务许可，严格门禁下不能作为正式写入口。实际行情准备由 PREDICTION_VERIFICATION 贯穿；不能用未实现的 market purpose 充当可用能力。
3. 先复现验证任务在许可登记等待中超过租约或总时限的行为；修复后确认不请求实际行情且持久终态可释放已登记许可。
4. 检查实际行情发布的固定版本和迟到写入保护，补足缺少的集成场景；运行涉及模块完整测试并独立审查。
5. 提交验证记录，再进入管理员生命周期接口。全局开关保持关闭。
