# 港股盘中实时报价试点

## 范围

第 2 项自选股入口与第 3 项股票分析页共用一套盘中报价。首个标的是腾讯控股，系统标识拟用 HK00700，富途订阅代码是 HK.00700。试点只在本机部署。继续以完整日线作为五日预测输入，港股的历史行情、预测、预警、持仓估值和跨股对比分别按已有能力判断。

## 现状与影响

2026-11-23 港股午盘在 OpenD 的本机 11111 端口收到五条不同报价时间的推送。后四条从报价时间到本机接收约 4.0 到 4.7 秒。已有市场目录查询和自选维护均只接受沪深代码，单加页面组件无法走通腾讯控股的搜索与自选。预测、预警和对比已有各自的沪深校验，首版保留这些校验。

## 接入

1. 由行情服务在已有证券目录增加一条港股试点记录。目录查询和自选支持该标的，按独立能力字段提示「支持盘中报价」「暂无日线」「暂不支持五日预测」。加入自选时根据市场能力决定是否创建日线补数任务。
2. Windows 上运行一个本机行情采集进程，连接已登录的 OpenD。一个上游订阅供页面复用，采集进程推送最新快照给行情服务的内部接口。由行情服务校验试点代码、港元价格和时间，再按行情时间保留最新快照。采集端只访问现有映射至本机的服务端口，OpenD 继续监听 127.0.0.1，内部接口使用独立的服务鉴权。
3. 页面复用现有认证网关读取报价，每 5 秒刷新可见页面，离开页面或浏览器进入后台时暂停。上游走推送，页面刷新只读系统快照。显示港元、报价时间、来源和状态。根据港股时段与采集连接状态区分等待报价、盘中更新、行情可能延迟、连接中断和已休市。盘中超时阈值可配置，结合实测校准。失联时保留最后报价及其时间，禁止用它冒充当前价。
4. 现有日线摘要、指标图和历史结果保留原时间和来源。分析页可独立显示盘中报价，日线缺失时仍能进入；预测、预警等操作根据实际支持能力显示。移除自选只改当前用户的自选记录。

## 实施与验收顺序

1. 测试并实现腾讯控股在搜索、详情和自选中的标识映射与能力判断。验证重复加入、移除和用户隔离。沪深搜索与自选补数流程做回归。
2. 测试并实现内部报价写入与读取。覆盖缺字段、错误币种、无效价格、乱序快照、重复推送、未授权请求和关闭开关。采集断开或重启后验证恢复订阅和乱序保护。
3. 接入自选股卡片和分析页。用交易时段实盘验证两页在不手动刷新的情况下更新，检查断线与休市提示、窄屏、键盘操作和刷新恢复。记录报价时间到服务接收、以及到页面显示的时间差。
4. 核对腾讯报价不会进入五日预测、历史验证或日线预警。验证沪深五日预测仍由已发布的模型和完整日线驱动。
5. 对外部署前核实供应商行情展示与转发授权，再决定开放范围。
