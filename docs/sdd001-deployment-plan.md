# SDD-001 部署与联调实施计划

日期：2026-09-30。依据：SDD-001；已有本机 Feign/H2 联调，不重新生成业务目录。

1. 准备本机 Compose：MySQL 8、Nacos、五业务服务、网关、算法与前端。生成忽略提交的本机凭据；仅监听本机回环地址，固定 Compose 项目名以避免影响其他容器。
2. 五服务配置各自数据库账号和 Nacos 注册；Feign 移除 Compose 环境中的固定地址。行情服务负责自身 Flyway 迁移。
3. 在行情依赖调用处接 Sentinel 异常熔断，先验证失败触发、打开拒绝与恢复，错误保持无成功数据。
4. 实际构建并启动 Compose，检查五库账号自己的连接和跨库拒绝、Nacos 五实例、预测→行情调用、停止/恢复行情，以及全服务重启。
5. 前端、网关和算法进行 HTTP/浏览器检查，保存验收脚本、版本与结果；审核差异后小步提交。CodeArts 实际源码差异仍作为独立验收项，未执行时不标完成。

决策：这是仅供本机开发的部署；Nacos 使用独立内部网络的 standalone 模式和回环端口，生产认证与高可用在部署规格中另行实现。各库账号获本库 DML 与当前迁移所需 DDL 权限，不能读取其他库；凭据不输出到日志或提交。
