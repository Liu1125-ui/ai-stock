# SDD006A 预警规则与通知偏好验收

日期：2026-10-10；项目：股票时序分析与辅助决策系统。A阶段已完成本机部署与验收；自动预警评价、站内通知及预警邮件属于后续B/C，尚未启用。

## 实现与业务边界

本人规则支持新建、分页查看、修改条件/阈值、启用和停用，包含四种严格比较条件。价格阈值通过十进制字符串传输，最多6位小数；涨跌幅最多4位且不超过100%。默认每用户50条，可配置ALERT_MAX_RULES。所有者从MS-01有效会话确定，管理员也不能用客户端owner读取他人规则。

MS-05独立持久化规则、请求幂等响应和通知偏好；用户级短事务独占锁保护数量和revision。行情HTTP在事务外，提交前复核边界时效。创建、条件变更及重新启用从MS-02取得真实RAW版本及交易日历，生效边界取最新行情日和当前应到期日的较晚者。停用不依赖行情。邮件接收意愿默认关闭，开启需核对本人当前已验证邮箱，不代表已经提供投递能力。

新公开接口为GET/POST /api/v1/alerts、PATCH /api/v1/alerts/{id}、GET/PATCH /api/v1/notification-preferences。网关使用精确方法/路径白名单；服务直连也检查会话、Origin和CSRF，写请求体上限4096字节。MS-05内部Feign连接/读取超时2/5秒，无自动重试、不跟随重定向；响应含错误正文在解码前限制为64KiB。内部边界不经网关公开。
