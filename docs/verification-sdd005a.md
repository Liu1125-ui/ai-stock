# SDD-005A：版本化预测输入验收

日期：2026-10-03。范围：预测输入准备，未发布模型、未开放用户正式预测；十三项业务、五服务与两角色设计不变。代码由Codex实现；CodeArts无本轮可核实源码差异。无Git remote、未push、未执行远程CI。

## 1. 已实现能力

1. Python分别获取Baostock RAW与后复权日线，验证代码、日期、口径、字段及完整自然日日历，输出候选。来源错误、部分返回、超时与单槽占用均明确失败。
2. MS-02将候选原始值与已发布RAW版本末60行逐一核对，保存独立输入、转换及日历快照。未来价格仍禁止入库；未来开闭市安排独立保存，不扩大原始行情日期范围。
3. 输入版本绑定rawVersionId、原始哈希、inputHash、calendarHash、来源定义与捕获时点。当前策略60行、5个目标交易日；默认取当前head对应且FRESH的快照，显式旧版本可复读并显示真实新鲜度。
4. 操作回执与快照在同一行情库事务写入；相同操作重放，同内容跨操作去重，同键改内容冲突，并发不会产生部分快照。RAW更新不重写既有输入。
5. 新增受服务认证的forecast-raw-window内部读取。公共日线接口保持用户Cookie要求。准备脚本只读忽略.env中的本机服务凭据，经HTTP发布，不直写数据库、不打印凭据。

第二次以相同KeyPrefix和ReuseSaved重放，三股均返回相同inputVersionId且replayed=true。现用RAW head仍为原三版本，revision2，各424条日线；没有改写RAW价格、日历或旧版本。只读数据库核对V1至V6迁移成功，三个快照各60条转换记录。

版本摘要见 [JSON证据](evidence/sdd005a-20261003.json)。原始来源候选、查询响应和运行日志保存在被忽略的runtime/sdd005a；不包含服务凭证，不将完整本机运行资料提交到Git。

## 4. 实施决定

1. 继续固定E:\aiStock工作目录及当前codex分支，遵从已授权的连续开发方式；没有另建工作树。若需要隔离可回滚本批提交或后续建立独立分支。
2. 既有日线是用户Cookie接口，新增专用内部60行读取，不扩大用户接口权限。代价为新增内部契约与维护回归；若内部调用协议后续调整，同步修改脚本和服务客户端。
3. 按真实返回扩展后复权价为DECIMAL(28,12)，用V6迁移保护已执行V5的校验和。代价为数据库字段扩展；超过该精度的来源仍明确拒绝，不静默舍入原值。因子比率仍按24,12与HALF_UP计算。
