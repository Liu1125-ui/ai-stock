# 验证邮件业务

作用：MS-05受理内部注册邮件请求，保存发送状态并恢复重试；不创建用户，不决定邮箱是否验证成功。

实现：稳定requestId与HMAC载荷摘要实现幂等；AES-256-GCM保存临时验证码载荷；短事务SKIP LOCKED认领，事务外SMTP发送，claim_version拒绝旧worker覆盖。失败采用5/30/120秒有限重试，成功/失败终止/到期清除临时载荷。SMTP使用SSL或强制STARTTLS并检查证书，日志不输出请求体或SMTP原始错误。

SMTP缺失返回503，不切换测试发送器。SMTP响应超时可能导致重复邮件，不声称恰好一次送达；邮箱验证仍由MS-01一次消费。
