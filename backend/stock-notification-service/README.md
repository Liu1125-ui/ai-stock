# 通知服务（MS-05）
作用：独立拥有注册验证码投递记录、预警规则和通知偏好，不跨库读取用户或行情。
实现：注册邮件保留既有内部令牌接口与工作器；新增公开规则接口解析MS-01会话，写操作校验Origin/CSRF。MS-02提供版本化生效边界，MS-05用户级独占行锁保护规则上限与revision，requestId保存创建结果以支持安全重试。
公开入口：GET/POST /api/v1/alerts，PATCH /api/v1/alerts/{id}，GET/PATCH /api/v1/notification-preferences。默认每用户50条（ALERT_MAX_RULES）；价格6位、涨跌幅4位小数。阈值十进制字符串，不静默舍入。
A阶段只管理规则与接收意愿，自动触发、站内通知和预警邮件投递尚未启用；不会因为保存偏好而发送邮件。注册验证码流程独立。
部署沿用deploy/compose.yaml和本机忽略.env。不要提交SMTP密码、服务令牌或数据库密码；测试用隔离stock_notification_test库。

A阶段本机验收已完成，记录见docs/verification-sdd006a.md。内部响应上限64KiB；缺少当前日历时创建/修改/重新启用受控拒绝，已有规则及停用保留。
