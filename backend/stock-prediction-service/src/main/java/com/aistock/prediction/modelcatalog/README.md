# 模型登记与审核发布

作用：MS-03拥有模型元数据、真实评价摘要、发布状态和推荐历史。方法：Python只读检查、同库锁/事务/CAS和操作回执；公开仅返回已发布摘要，管理员权限由MS-01会话解析。原制品和评价不覆盖，跨服务不联表。

发布生命周期：MS-01解析的ADMIN身份、显式理由/局限确认、模型及head revision；事务锁顺序head→version，状态/推荐/追加事件一次提交。operationId绑定actor和规范请求，重复返回原回执；发布/推荐/回滚重新检查只读制品。

检查客户端以128KiB BodySubscriber与15秒完整响应Future共同限制大小及时间；无论失败、超时或取消都终止传输订阅，不仅等待响应头。

SDD-005D1 publication只读契约：内部服务身份再次核验后同库锁head读取PUBLISHED模型descriptor，返回固定UUID/制品/hash/revision；候选、未采用或下线409，未知404，网关不代理。供算法核验真实业务发布状态，不读取其他服务数据库。
