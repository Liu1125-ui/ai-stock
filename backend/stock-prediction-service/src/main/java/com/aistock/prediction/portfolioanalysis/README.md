# 持仓估值分析
作用：核验本人持仓和已发布RAW报价，使用定点规则计算并保存不可变证据。
实现：严格源协议、BigDecimal逐行舍入和显示额加总、完整性与新鲜度分开、所有结果归本人；后续通过独立HTTP编排和操作租约衔接。不得调用模型、采集供应商、跨库访问或在日志记录数量/成本/会话。

跨服务顺序固定为claim→本人快照→固定日期报价→定点计算→原会话本人版本重查→本地完成。配置默认并发2（允许1—8）、处理30秒、租约45秒；请求重放不采集新证据。内部HTTP连接2秒、快照5秒/报价8秒/版本3秒、响应256KiB、无应用重试与重定向；行情调用经既有熔断器。公开写入仅requestId，Cookie取最后一个同名值，与认证过滤器一致。

Task5B: 非空持仓经原快照校验后绑定股票全集，行情RPC带凭据并核对RAW全集；空仓不登记。原期限和revision复核不改，结果提交后通知。使用记录不含会话/数量/成本，历史查询不重新取数。
