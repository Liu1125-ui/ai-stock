# 注册挑战与限频

作用：保存注册前的验证码挑战和持久化操作限频。

实现：挑战无需用户外键；使用SQL条件更新实现过期拒绝、失败次数上限和一次消费。ChallengeRepository.consume仅改变状态，注册服务仍须先核对验证码摘要，并在同一事务中创建账号。锁定挑战要求活跃事务。

RateLimitService将邮箱与可信来源映射为HMAC桶键，按固定顺序锁桶并在一个事务中增加计数，防止并发绕过冷却期或部分计数提交。次数及冷却期使用Policy配置。

RegistrationService在邮箱锁与挑战锁保护下创建USER账号、消费验证码并写回执；错码以事务结果返回，提交错误计数后再抛业务错误。RegistrationDispatcher持久化加密意图并使用稳定请求ID调用MS-05，短事务租约认领、版本保护、有限重试。客户端未配置或不可用时保留受理意图并明确发送状态；ACCEPTED不表示收件人收到邮件。

HTTP注册接口已建立，浏览器安全、登录及页面将由后续任务接入，尚不能作为完整账号业务验收。已有账号申请返回统一受理但没有可消费注册挑战。
