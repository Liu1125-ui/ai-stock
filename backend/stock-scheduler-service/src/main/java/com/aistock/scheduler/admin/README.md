# 管理员任务只读查询

公开展示DTO与严格筛选/游标契约独立于内部执行对象；原因码只经过有限映射展示。仓储仅读取调度服务自己的数据库，接口需要逐请求校验管理员会话。

查询服务在只读REPEATABLE_READ事务中调用本库仓储；列表按时间/ID倒序、尝试按原序号升序游标分页，不承诺跨页状态冻结。

SDD-009B操作契约独立于内部attempt，版本以字符串对外传输；输入仅允许operationId/expectedRevision/reasonCode。AdminTaskActionPolicy是能力提示与行锁内命令校验的共用纯政策：状态、租约、错误白名单、worker、普通任务冷却、比较原周期/预算均不得由前端绕过。当前阶段尚未开放写接口。

AdminTaskActionRepository在单个调度库短事务内登记操作、锁定任务、复核版本/政策、更新任务并保存APPLIED或REJECTED；相同编号相同内容返回原回执，冲突不覆盖。没有任务HTTP执行。历史为只读游标查询，超时原回执仅创建者可读；默认操作入口关闭，旧内部接口不因此公开。

AdminTaskActionController公开能力、命令、原操作回执与历史；409保留data回执而非使用null-data失败工厂。正文有界读取4097字节并严格验证，Controller仅使用服务器绑定principal；公开命令不直接调用worker。实际生产写入口仍需配置及验收才启用。

生命周期明确拒绝使用安全中文原因，仍遵守原重试/取消策略，未扩大管理员操作范围。
