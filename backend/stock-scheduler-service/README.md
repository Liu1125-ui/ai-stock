# 调度服务

作用：拥有独立 stock_scheduler 数据库，保存行情更新计划、任务与每次执行记录。当前已实现持续行情更新，不代表预测、实验、预警调度均已完成。

实现方法：每日北京时间 20 点计算最新到期任务，重启补最新一天；幂等键防重复，数据库短事务及行锁领取。HTTP 调用发生在事务外，由 MS-02 采集、校验和发布。90 秒尝试租约、最多三次自动尝试、受控退避；响应不确定时查询执行回执，先核对再决定重试。调度仅保存行情版本引用，不访问行情数据库。

操作：内部任务接口必须有服务身份，网关不公开。使用 ../../scripts/refresh-market.ps1 查看、提交、查看尝试、重试失败任务或取消尚未执行任务。MARKET_WORKER_ENABLED / MARKET_PLAN_ENABLED 模板默认 false；核验来源后可显式开启。MARKET_PLAN_INSTRUMENTS 是可配置列表，仅支持已有真实行情版本的证券。

独立运行：backend 目录下按 cli-build 构建；本机 Compose 端口 18084。完整验收见 ../../docs/verification-sdd004.md，自动化数据库测试使用独立测试库。
