# 持仓估值报价
作用：为持仓分析提供只读、可追溯的已发布未复权收盘价证据。
实现：服务认证过滤器先验身份；严格解析固定日期与最多100个证券代码；一个5秒只读REPEATABLE_READ事务读取head、版本、索引末条实际成交价格和独立日历。停牌沿用旧成交日并标注；未知日历保留有效价格，明确日历冲突则拒绝估值。不采集供应商、不写行情、不调用模型。
