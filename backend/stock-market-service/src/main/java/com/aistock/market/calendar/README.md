# 独立交易日历
作用：维护来源可追溯的不可变日历版本，供日线预警判定截止日，不修改行情和预测快照。
实现：HTTP采集发生事务外，校验连续自然日/标志/规范哈希及采集时效；同库版本/操作回执/当前头短事务提交，按provider串行，旧响应不倒退头。CalendarService只通过方法对外提供对象，不直接读取Spring代理字段。
接口仅服务令牌可访问，网关不公开。GET读取当前快照不等同一定覆盖所需日期；covering从历史版本选择最新且满足所需范围及默认7天TTL的快照，避免未来子区间遮蔽当前覆盖。POST刷新由后续调度接入，本切片不启用自动扫描。来源失败、截断或超期不会覆盖好版本。

## SDD006B2覆盖读取
内部GET新增可选且必须成对的start/end，严格拒绝重复/未知参数及非法/倒置/400天以上范围；通过covering选最新且覆盖要求/TTL有效的不可变版本，无覆盖503。默认无参数GET仍为审计当前头，不保证覆盖任意区间。调度每日刷新[today-366,today]并按该范围读取，避免未来短历史头阻塞扫描。本机已部署，见docs/verification-sdd006b2.md。
